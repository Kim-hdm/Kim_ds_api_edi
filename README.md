DeepSeek 网页版和 App 的免费版有使用上限。本项目让你使用自己的 DeepSeek 官方付费 API key，从而不受这些免费额度限制。你的 API key 不会被存储。

Why this project? The DeepSeek website and app have usage limits on their free tier. This project lets you use your own DeepSeek API key (paid, official API) instead, so you are not constrained by those free-tier limits. Your API key is never stored.
