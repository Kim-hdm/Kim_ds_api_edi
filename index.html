API 设置

Key 仅保存在本机浏览器 localStorage，不会上传到其他服务器；源码内不内置任何密钥。
默认官方地址；如需走代理可替换为兼容 OpenAI 格式的网关。
联网搜索使用 DeepSeek 服务端工具 deepseek_web_search，需选择 deepseek-flash 并连接官方接口；第三方网关可能不支持。
图片会先在本地压缩（最长边 1280px、JPEG），再以 OpenAI 视觉格式 image_url（data URL）随消息发送；需要模型与接口支持图片输入。
文件上传支持 txt / md / json / html / csv / xml / yaml / 代码等文本类文件，内容会随消息一起发送给模型；PDF、Word、Excel、压缩包等二进制文件暂不支持。
发出第一句后先用本地规则生成临时标题；第一问的回答完成后，结合问答整理成「陈述式短标题」（「微软创始人是谁」→「微软创始人是比尔盖茨」）。答案太长时退回主题式标题（「怎么做蛋糕」→「蛋糕制作指南」），不会把清单/步骤塞进标题。没有 Key 或模型不可用时保留本地标题；手动重命名后不再自动改写。
支持 Classic(ghp_) / Fine‑grained(github_pat_) token；细粒度需要授予Gist读写权限。
Fine‑grained：Gists → Read and write；Token只存本机浏览器。
同一个 Gist ID 即在多台设备间共享同一份历史；不要把 ID 和 Token 泄露给他人。
